Case Study // E-Commerce

Elite Touch Collections

An African fashion storefront that removes traditional checkout friction by connecting shoppers directly to WhatsApp order fulfillment in Ghana Cedis (₵).

01 // The Challenge

The Problem

Traditional e-commerce checkout funnels fail for boutique fashion brands in West Africa. Customers hesitate to enter credit card numbers on generic payment gateways; instead, they want to speak with the shop owner to confirm fabric availability, customized sizing, and delivery logistics.

Elite Touch Collections needed an online storefront that aligns with authentic local purchasing habits: enable customers to browse rich photo galleries, filter by style, build a cart, and checkout seamlessly over WhatsApp.

02 // The Solution

Key Architectural Features

Built a lightning-fast catalog with an interactive JavaScript cart drawer that automatically serializes items into a clean, pre-filled WhatsApp message.

FEATURE 01

Interactive Cart Drawer

Slide-out drawer calculating subtotals, quantity adjustments, and removal state in real-time using localStorage persistence.

FEATURE 02

One-Tap WhatsApp Checkout

Generates an encoded WhatsApp API URL with the customer's cart list, selected sizes, total price in ₵, and delivery address inquiry.

FEATURE 03

Category Filtering & Search

Instant client-side filter system organizing collections into Casual, Occasion, Boubou, and Two-Piece silhouettes.

FEATURE 04

Lightweight Image Sliders

Touch-friendly hero carousel and multi-angle product image slider built in vanilla JS without bulky third-party libraries.

04 // Engineering

Tech & Approach

  • Conversational Commerce: Eliminated gateway fees, credit card drops, and complex merchant account approvals for the store owner.
  • State-Driven Vanilla Cart: Written in clean ES6 modules with localStorage syncing, ensuring items remain in the cart across page navigations.
  • Fast Mobile Catalog: Optimized for handheld shoppers on 4G networks with responsive WebP image galleries.
  • Accessible Controls: Custom drawer modal with keyboard trap, escape-to-close behavior, and ARIA modal attributes.
