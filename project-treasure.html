Treasure International School

A polished, six-page institutional web experience presenting curriculum excellence, admissions pathways, and events with clean vanilla engineering.

01 // The Challenge

The Problem

Treasure International School needed an official digital presence that reflected the rigor and warmth of its educational standards. Previously, parents lacked a single authoritative source to check curriculum details, admissions requirements, and upcoming academic events.

The solution needed to be easily maintainable by the school's administrative team without complex build tooling or ongoing server maintenance overhead.

02 // The Solution

Key Architectural Features

Crafted a unified six-page site built purely on vanilla web standards. Deployable directly to any static web host or CDN with zero compilation dependencies.

FEATURE 01

Shared Design Tokens

Centralized CSS custom properties governing colors, fluid typography clamp curves, spacing scales, and elevated shadow tokens across all six pages.

FEATURE 02

Reusable Navigation Script

Modular JavaScript controller handling mobile dropdown toggling, active page state detection, and keyboard accessibility without code duplication.

FEATURE 03

Scroll-Reveal Engine

Lightweight IntersectionObserver scroll reveal system adding subtle editorial elegance without dragging down mobile CPU or frame rates.

FEATURE 04

Direct Parent Inquiries

Interactive admissions intake and contact pages that route parent messages directly to school administrative email channels.

03 // Architecture

Pages & Structure

The 6-page site maps the key parent discovery stages from initial school introduction to formal enrollment:

Home (index.html)
About (about.html)
Academics (academics.html)
Admissions (admissions.html)
Events (events.html)
Contact (contact.html)
04 // Engineering

Tech & Approach

  • No Build Step: Directly executable in any browser. Zero npm install, zero vulnerability patches, zero broken lockfiles over time.
  • CSS Grid Layouts: Dynamic 12-column responsive grids adapting seamlessly from narrow smartphones (360px) to ultra-wide displays.
  • Progressive Enhancement: Core educational content remains 100% accessible and readable even if JavaScript is disabled.
  • Optimized Asset Loading: Responsive WebP image tags with descriptive alt attributes and native lazy-loading attributes (`loading="lazy"`).
05 // Outcomes

The Result

A dependable institutional hub that parents and educators praise for simplicity and quick page transitions.
